# About Workbench_MVP_Design_Specification.md

The WorkBench_MVP_Design_Specification.md file is the stable “north star” for the project. 

Create a second document called IMPLEMENTATION_NOTES.md that evolves as the codebase grows. 

The design document should change rarely and only when the product vision changes; implementation notes can change frequently as you learn from building the MVP. That separation helps keep the architecture coherent over time.
